# Личный кабинет библиотеки DEXEL 3D

Каталог работает как статическая страница GitHub Pages. При пустых ключах доступны встроенные модели, 3D-просмотр, локальное добавление STL и сохранение PNG. После подключения Supabase новые модели авторов сохраняются в облаке и видны всем посетителям каталога.

## Подключение

1. Создайте проект в Supabase. В **SQL Editor → New query** вставьте весь файл [supabase.sql](supabase.sql) и нажмите **Run**. Скрипт создаёт таблицу `public.models`, публичный бакет `stl-models`, политики доступа и функцию подсчёта статистики.
2. В **Authentication → URL Configuration** укажите `https://dexel3d.ru/catalog/` и в **Site URL**, и в списке **Redirect URLs**. В настройках входа включите провайдер **Email**. Для подтверждения e-mail обычных посетителей настройте [свой SMTP-сервис](https://supabase.com/docs/guides/auth/auth-smtp). Встроенная почта Supabase доставляет письма членам команды проекта.
3. Скопируйте **Project URL** и публичный **Publishable key** из окна **Connect**. В начале [script.js](script.js) заполните константы:

   ```js
   const SUPABASE_URL = 'https://ваш-проект.supabase.co';
   const SUPABASE_ANON_KEY = 'sb_publishable_ваш_публичный_ключ';
   ```

   В старом проекте вместо Publishable key подходит публичный ключ `anon`. Ключи `service_role` и `sb_secret_…` предназначены для сервера.

4. Сохраните файл, опубликуйте его через GitHub Pages и откройте [каталог](https://dexel3d.ru/catalog/). Войдите, опубликуйте пробную модель и откройте каталог в другом браузере. В личном кабинете доступны редактирование и удаление.

## Обложка и статистика

В форме выберите STL, затем настройте **поворот** и **наклон**. Новая версия PNG появляется после отпускания ползунка. При редактировании можно изменить ракурс действующего STL либо выбрать другой файл. «Скачать готовую обложку (PNG)» сохраняет выбранный ракурс.

Для своей обложки выберите фото JPG, PNG или WebP до 10 МБ. Каталог показывает его целиком и сохраняет в PNG. Фото можно заменить при редактировании модели. Чтобы снова получить 3D-рендер, нажмите «Создать обложку из STL».

Счётчики фиксируют клики по просмотру, скачиванию и переходу к заказу для облачных моделей. Скачивание учитывается по клику, а заказ — по переходу в форму. Запись и файлы может править только их владелец. Локально добавленные ранее модели доступны в этом браузере. Для публикации такой модели выберите её STL в облачной форме.

SQL рассчитан на новый проект или повторный запуск в проекте, где таблица была создана этим скриптом. Если в проекте уже есть таблица `models` с иной схемой, сначала согласуйте её структуру с миграцией.

## Характеристики моделей

Для существующей базы выполните [model-geometry.sql](model-geometry.sql) в SQL Editor. Категория уже хранится в `category`. Новая колонка `geometry_metrics` хранит ширину, глубину и высоту в миллиметрах и объём в см³. У старых записей колонка пуста, каталог рассчитывает характеристики при показе карточки. После миграции новые загрузки сохраняют их вместе с моделью.

Расход пластика оценивается по заполнению `INFILL` (25%) и плотности `DENSITY_G_CM3` (1,25 г/см³). Настройки находятся в начале `script.js`.

Расчёт объёма предполагает замкнутую сетку с согласованным направлением треугольников. Оценка расхода не учитывает стенки, поддержки и технологические потери. Точное время печати зависит от профиля слайсера.

## Социальные функции и массовая загрузка

Выполните [social.sql](social.sql) в SQL Editor уже подключённого проекта Supabase. Скрипт можно запустить повторно. Он создаёт четыре таблицы, публичный бакет фотографий `catalog-social` и политики доступа. Текущие таблица `models` и бакет STL сохраняются.

Избранное и фотографии доступны для опубликованных моделей и встроенных демонстрационных STL. Сохранённые только в браузере модели можно загрузить в облако, чтобы использовать социальные функции. Пользователь управляет статусом собственных идей и выбирает опубликованную модель для статуса «Готово». Голосование за собственную идею отключено. Пакетная загрузка принимает до 50 STL и продолжает обработку после ошибки отдельного файла.

Фотографии размером до 10 МБ уменьшаются до 1280 пикселей по длинной стороне и сохраняются как JPEG. Для новых STL используются текущие настройки генерации обложки. Если миграция характеристик ещё не выполнена, они рассчитываются при открытии карточки.

### Расширенные категории и необязательное описание

Категории задаются единым массивом `CATEGORIES` в `script.js`: доступны в редакторе, массовой загрузке, импорте Google Диска и фильтрах. Добавлены декор, вазы, кухня, инструменты, запчасти, крепления, электроника, игрушки, миниатюры, косплей, сад, спорт, товары для животных, обучение и прототипы.

Для существующей базы выполните `catalog/optional-description.sql` в Supabase SQL Editor **до публикации обновлённого клиента**. Миграция разрешает пустое описание модели, сохраняет тексты прежних моделей и ограничение 500 символов. Для новой установки правило уже включено в `supabase.sql`. Описание не заполняется автоматически; название и STL для новой модели остаются обязательными. Требования к описаниям заявок на «Столе заказов» не меняются.
